# APTrades — Shared Hosting Deployment Guide

## Quick Start (Namecheap / Ultahost)

### Step 1: Upload Files
1. Zip the entire `laravel-platform/` folder
2. Upload to your hosting via cPanel File Manager or FTP
3. Extract into your `public_html/` directory (or the root folder your domain points to)

Your directory structure should look like:
```
public_html/
├── app/
├── bootstrap/
├── config/
├── database/
├── public/
│   ├── index.php
│   ├── .htaccess
│   └── ...
├── resources/
├── routes/
├── storage/
├── .htaccess          ← Auto-generated by installer
├── artisan
└── ...
```

### Step 2: Create MySQL Database
**Namecheap (cPanel):**
1. Go to cPanel → MySQL® Databases
2. Create a new database (e.g., `youruser_aptrades`)
3. Create a new database user
4. Add the user to the database with **ALL PRIVILEGES**

**Ultahost (DirectAdmin/hPanel):**
1. Go to your hosting panel → MySQL Management
2. Create a new database and user
3. Grant the user **ALL PRIVILEGES** on the database

### Step 3: Run the Installer
1. Open your browser and go to:
   ```
   https://yourdomain.com/install
   ```
2. The installer will check server requirements
3. Enter your database credentials (from Step 2)
4. Create your admin account
5. Click "Run Installation"
6. Done! The platform is ready to use

### Step 4: Post-Installation
1. Log in at `https://yourdomain.com/login` with your admin credentials
2. Go to **Admin → Settings → Deposit Addresses** and replace demo crypto addresses
3. Go to **Admin → Edit Landing Page** to customize your content
4. Go to **Admin → Settings → Tawk.to Chat** to enable live chat (optional)
5. Review and adjust investment packages in **Admin → Packages**

## Folder Permissions

If the installer can't set permissions automatically, manually set:
```
chmod 755 storage/
chmod 755 storage/app/
chmod 755 storage/framework/
chmod 755 storage/framework/cache/
chmod 755 storage/framework/sessions/
chmod 755 storage/framework/views/
chmod 755 storage/logs/
chmod 755 bootstrap/cache/
```

## If .htaccess Doesn't Work (Alternative Method)

If your domain doesn't auto-route to `public/`, you can:

### Option A: Change Document Root (Preferred)
In cPanel → Domains, set your domain's document root to:
```
public_html/public
```

### Option B: Move index.php to root
If you can't change the document root, the installer's `.htaccess` should handle routing. If it doesn't:

1. Copy `public/index.php` to `public_html/index.php`
2. Edit the copied file and change the paths:
   ```php
   require __DIR__.'/vendor/autoload.php';
   $app = require_once __DIR__.'/bootstrap/app.php';
   ```

## SSL/HTTPS Setup

1. In cPanel → SSL/TLS → Manage SSL sites
2. Install a free Let's Encrypt SSL certificate for your domain
3. Force HTTPS by adding to your `.htaccess`:
   ```
   RewriteCond %{HTTPS} off
   RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
   ```

## Troubleshooting

**"500 Internal Server Error"**
- Check that `storage/` and `bootstrap/cache/` are writable
- Check `.env` file has correct database credentials
- Check PHP version is 8.2+ (cPanel → MultiPHP Manager)

**"Database connection failed"**
- Verify database name, user, and password in cPanel → MySQL Databases
- On Namecheap, database names are prefixed with your cPanel username
- Try `127.0.0.1` instead of `localhost` for the host

**"Storage symlink failed"**
- This is normal on some shared hosts. The installer creates a fallback automatically.
- Or manually create the symlink via cPanel Terminal: `php artisan storage:link`

**"Page shows blank or file listing"**
- Make sure `.htaccess` exists in the root directory
- Make sure `mod_rewrite` is enabled (it is by default on Namecheap/Ultahost)
- Try setting document root to `public_html/public`
