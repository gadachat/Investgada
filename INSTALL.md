## Quick Install (Web Wizard)

The fastest way to deploy. The platform includes a built-in 4-step web installer.

### Step 1: Upload Files

Upload all project files to your server's public directory:
- **cPanel**: Upload to `public_html/`
- **VPS**: Upload to `/var/www/investgada/`
- Use Git clone or ZIP upload

```bash
# Via Git
cd /var/www/
git clone https://github.com/gadachat/Investgada.git investgada
cd investgada
```

### Step 2: Install Dependencies

```bash
composer install --no-dev --optimize-autoloader
```

If composer is not installed:
```bash
curl -sS https://getcomposer.org/installer | php
php composer.phar install --no-dev --optimize-autoloader
```

### Step 3: Set Permissions

```bash
chmod -R 775 storage
chmod -R 775 bootstrap/cache
chmod -R 775 public/storage
```

### Step 4: Point Domain to Public Directory

Your web server's document root should point to the `public/` subdirectory:
- **cPanel**: Set document root to `public_html/public`
- **Nginx**: Set `root /var/www/investgada/public;`
- **Apache**: The included `.htaccess` handles routing

### Step 5: Run the Web Installer

Open your browser and visit:
```
https://yourdomain.com/install
```

The installer will guide you through:

1. **Requirements Check** — Verifies PHP version, extensions, permissions
2. **Database Configuration** — Enter your DB credentials, app name, URL
3. **Admin Account Setup** — Create your admin username, email, password
4. **Automatic Installation** — The system will:
   - Generate APP_KEY
   - Run all migrations (29 migrations, 47 tables)
   - Create storage symlink
   - Set folder permissions
   - Create your admin account
   - Seed default settings (platform config, ranks, features)
   - Seed default investment packages
   - Seed default deposit addresses
   - Clear caches

Once complete, you'll be redirected to the admin login page.

### Step 6: Login

- **Admin login**: `https://yourdomain.com/admin/login`
- **User login**: `https://yourdomain.com/login`

## Manual Installation

For advanced users who prefer command-line setup.

```bash
# 1. Clone the repository
git clone https://github.com/gadachat/Investgada.git
cd Investgada

# 2. Install PHP dependencies
composer install --no-dev --optimize-autoloader

# 3. Copy environment file
cp .env.example .env

# 4. Generate application key
php artisan key:generate

# 5. Edit .env file with your settings
# Use your preferred editor (nano, vim, etc.)
nano .env
```

### .env Configuration

```env
APP_NAME=YourPlatform
APP_ENV=production
APP_KEY=                  # Auto-generated by key:generate
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

# Mail (for email notifications)
MAIL_MAILER=smtp
MAIL_HOST=your-smtp-host.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your-email-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@yourdomain.com
MAIL_FROM_NAME="${APP_NAME}"

# Filesystem
FILESYSTEM_DISK=public
```

```bash
# 6. Run migrations
php artisan migrate --force

# 7. Seed default data
```


## Shared Hosting (cPanel)

Special instructions for shared hosting environments.

### Upload via cPanel File Manager

1. **Zip the project** on your computer (excluding `vendor/` and `node_modules/`)
2. Go to **cPanel → File Manager → public_html**
3. Upload the ZIP file
4. Extract it — your structure should be:
   ```
   public_html/
     ├── app/
     ├── bootstrap/
     ├── config/
     ├── database/
     ├── public/          ← This is your web root
     ├── resources/
     ├── routes/
     ├── storage/
     ├── vendor/          ← After composer install
     ├── .env
     ├── artisan
     └── composer.json
   ```

### Install Composer via cPanel

1. Go to **cPanel → Software → Terminal** (if available)
2. Run:
   ```bash
   cd ~/public_html
   composer install --no-dev --optimize-autoloader
   ```

If no Terminal access:
1. Go to **cPanel → Software → Select PHP Version**
2. Enable these extensions: `pdo_mysql, mbstring, gd, zip, curl, bcmath`
3. Install Composer locally:
   ```bash
   curl -sS https://getcomposer.org/installer | php
   php composer.phar install --no-dev --optimize-autoloader
   ```

### Fix Document Root for Shared Hosting

Most cPanel setups serve from `public_html/`, but Laravel needs `public_html/public/`.

**Option A: Move public contents (recommended)**
```bash
# Move everything from public/ to public_html/
mv public/* public_html/
mv public/.htaccess public_html/

# Update index.php paths
# Edit public_html/index.php and change:
#   require __DIR__.'/../vendor/autoload.php';
#   $app = require_once __DIR__.'/../bootstrap/app.php';
# These should already work since the app is in public_html/
```

**Option B: Use .htaccess rewrite (alternative)**
Create `public_html/.htaccess` with:
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>
```

### Set Up Cron on cPanel

1. Go to **cPanel → Cron Jobs**
2. Add this command to run **every minute**:
   ```
   * * * * * cd /home/username/public_html && php artisan schedule:run >> /dev/null 2>&1
   ```
   Replace `username` with your cPanel username.

### Storage Symlink on Shared Hosting

If `php artisan storage:link` fails:
```bash
# Create the symlink manually
ln -s ~/public_html/storage/app/public ~/public_html/public/storage
```

If symlinks are disabled on your host:
1. Create `public_html/public/storage/` directory
2. The platform has a built-in fallback that handles this automatically

## VPS / Dedicated Server

### Nginx + PHP-FPM Setup

```bash
# 1. Install dependencies (Ubuntu/Debian)
sudo apt update
sudo apt install -y nginx php8.2-fpm php8.2-mysql php8.2-mbstring \
    php8.2-xml php8.2-curl php8.2-gd php8.2-zip php8.2-bcmath \
    mysql-server composer

# 2. Clone the project
sudo mkdir -p /var/www/investgada
sudo chown $USER:$USER /var/www/investgada
cd /var/www
git clone https://github.com/gadachat/Investgada.git investgada
cd investgada

# 3. Install dependencies
composer install --no-dev --optimize-autoloader

# 4. Set up environment
cp .env.example .env
php artisan key:generate
nano .env  # Configure database and URL

# 5. Run migrations and seed
php artisan migrate --force
php artisan db:seed --force
php artisan storage:link

# 6. Set ownership and permissions
sudo chown -R www-data:www-data /var/www/investgada
sudo chown -R $USER:www-data /var/www/investgada
sudo chmod -R 775 storage bootstrap/cache public/storage
```

### Nginx Configuration

```nginx
# /etc/nginx/sites-available/investgada
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/investgada/public;
    index index.php index.html;

    charset utf-8;
    client_max_body_size 20M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $real_root_path$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }
}
```

```bash
# Enable the site
sudo ln -s /etc/nginx/sites-available/investgada /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# Install SSL with Certbot
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com
```

### Set Up Systemd Service for Queue Worker (Optional but Recommended)

```ini
# /etc/systemd/system/investgada-queue.service
[Unit]
Description=APTrades Queue Worker
After=network.target

[Service]
Type=simple
User=www-data
Group=www-data
Restart=always
ExecStart=/usr/bin/php /var/www/investgada/artisan queue:work --sleep=3 --tries=3 --max-time=3600
WorkingDirectory=/var/www/investgada

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable investgada-queue
sudo systemctl start investgada-queue
```

### Set Up Cron on VPS

```bash
sudo crontab -u www-data -e
```
Add:
```
* * * * * cd /var/www/investgada && php artisan schedule:run >> /dev/null 2>&1
```

## Cron Jobs Setup

The platform relies on scheduled tasks for automated operations. **This is critical** — without cron jobs, profits, commissions, and rank promotions won't process automatically.

### Available Cron Commands

| Command | Frequency | Description |
|---------|-----------|-------------|
| `cron:investment-payouts` | Daily | Distributes daily ROI profits to investors |
| `cron:referral-commissions` | On-demand | Processes pending referral commissions |
| `cron:matching-bonus` | On-demand | Calculates and pays binary matching bonuses |
| `cron:rank-advancement` | Daily | Auto-promotes users who qualify for higher ranks |
| `cron:cleanup` | Daily | Removes expired pending deposits/withdrawals |
| `cron:auto-trades` | Hourly | Generates and closes auto-trades for active sessions |
| `cron:run-all` | All-in-one | Runs all the above in sequence |

### Recommended: Use Laravel Scheduler (One Cron Entry)

Add this single line to your server's crontab:
```bash
* * * * * cd /path/to/Investgada && php artisan schedule:run >> /dev/null 2>&1
```

Laravel's built-in scheduler handles all timing automatically. This is the **recommended approach**.

### Alternative: Run Individual Commands

If you can't run the scheduler every minute, you can set up individual crons:

```bash
# Daily at midnight — investment payouts
0 0 * * * cd /path/to/Investgada && php artisan cron:investment-payouts >> /dev/null 2>&1

# Daily at 00:30 — rank advancement
30 0 * * * cd /path/to/Investgada && php artisan cron:rank-advancement >> /dev/null 2>&1

# Daily at 01:00 — cleanup
0 1 * * * cd /path/to/Investgada && php artisan cron:cleanup >> /dev/null 2>&1

# Every hour — auto trades
0 * * * * cd /path/to/Investgada && php artisan cron:auto-trades >> /dev/null 2>&1
```

### Manual Execution

You can also run any cron job manually from the admin panel:
- **Admin → Settings → Cron Jobs** — View all commands and copy-paste

Or via SSH:
```bash
# Run all jobs at once
php artisan cron:run-all

# Run specific job
php artisan cron:investment-payouts

# Dry run (see what would happen without making changes)
php artisan cron:run-all --dry-run
```

## Troubleshooting

### Blank White Page

**Cause**: PHP error not being displayed.

**Fix**:
```bash
# Check error logs
cat storage/logs/laravel.log | tail -50

# Temporarily enable debug
# In .env: APP_DEBUG=true
# Then refresh and check for the error message
```

### 500 Internal Server Error

**Common causes**:
1. Missing `.env` file → Run `cp .env.example .env && php artisan key:generate`
2. Wrong file permissions → `chmod -R 775 storage bootstrap/cache`
3. Missing PHP extension → Check required extensions list
4. Database connection failed → Check `.env` DB credentials

```bash
# Diagnostic commands
php artisan config:clear
php artisan cache:clear
php artisan view:clear
php artisan route:clear
chmod -R 775 storage bootstrap/cache
```

### "No application encryption key has been specified"

```bash
php artisan key:generate
php artisan config:clear
```

### Storage/Upload Issues

```bash
# Recreate storage symlink
rm public/storage
php artisan storage:link

# Check permissions
chmod -R 775 storage
chmod -R 775 public/storage

# If symlink fails (shared hosting)
mkdir -p public/storage
cp -r storage/app/public/* public/storage/
```

### Database Migration Errors

```bash
# Fresh migration (WARNING: deletes all data)
php artisan migrate:fresh --seed --force

# If specific migration fails, check:
php artisan migrate:status
```

### Cron Jobs Not Running

1. Verify crontab is set: `crontab -l`
2. Test manually: `php artisan schedule:run`
3. Check cron service: `sudo systemctl status cron`
4. Verify PHP path: `which php` (use full path in crontab if needed)
5. Check error log: `cat storage/logs/laravel.log | tail -20`

### Asset/CSS Not Loading

```bash
# If using Vite (optional)
npm install
npm run build

# If not using Node.js, the platform uses CDN-loaded Bootstrap 5 and ApexCharts
# Make sure your server allows external CDN requests
```

### Installer Page Not Accessible

The installer only works when the platform is NOT yet installed. If you need to re-run it:
```bash
# Remove the installed marker
rm storage/app/installed

# Clear the database (WARNING: deletes all data)
php artisan migrate:fresh --force

# Visit /install again
```

### Login Redirect Loop

```bash
# Clear all caches
php artisan optimize:clear

# Check sessions directory is writable
chmod -R 775 storage/framework/sessions
```

### "Class not found" Errors

```bash
# Regenerate composer autoloader
composer dump-autoload

# Clear all caches
php artisan optimize:clear
php artisan config:cache
php artisan route:cache
```

## Security Hardening

After installation, follow these steps to secure your platform:

### 1. Secure the Admin Panel

```bash
# In .env, set:
APP_DEBUG=false

# Enable 2FA for all admin accounts
# Admin → Security → 2FA → Enable
```

### 2. File Permissions

```bash
# Set restrictive permissions
find /var/www/investgada -type f -exec chmod 644 {} \;
find /var/www/investgada -type d -exec chmod 755 {} \;
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data /var/www/investgada
```

### 3. Firewall (VPS only)

```bash
# Only allow HTTP, HTTPS, and SSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 22/tcp
sudo ufw enable
```

### 4. Database Security

```sql
-- Create a dedicated database user (not root)
CREATE USER 'investgada'@'localhost' IDENTIFIED BY 'StrongPassword123!';
CREATE DATABASE investgada;
GRANT ALL PRIVILEGES ON investgada.* TO 'investgada'@'localhost';
FLUSH PRIVILEGES;
```

### 5. Disable Directory Listing

Add to `public/.htaccess` (already included):
```apache
Options -Indexes
```

### 6. Set Up Regular Backups

```bash
# Database backup cron (daily at 2 AM)
0 2 * * * mysqldump -u username -p'password' investgada > /backups/investgada_$(date +\%Y\%m\%d).sql

# Keep only last 30 days of backups
0 3 * * * find /backups/ -name "investgada_*.sql" -mtime +30 -delete
```

### 7. Environment File Protection

The `.env` file is already protected by:
- `.htaccess` rule denying access to dotfiles
- Nginx configuration blocking dotfile access

Verify by trying to access `https://yourdomain.com/.env` — it should return 404 or 403.

### 8. Enable HTTPS

```bash
# Using Let's Encrypt (free SSL)
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# Auto-renew
sudo crontab -l | { cat; echo "0 12 * * * /usr/bin/certbot renew --quiet"; } | sudo crontab -
```
